## Candidate universe U (40 closures, frozen semantics)

Deterministic Grid->Grid, unresolvable/degenerate cases -> identity
(house rule); objects = 4-connected same-color components vs bg =
most common color (house rule); "largest/smallest" ties by
(size, topmost-leftmost). None derived from eval data or per-task
probe rows; NONE is in v4.

Object-axis geometry (8): RotLargest90, RotLargest180,
MirrorLargestH, MirrorLargestV (largest object transformed in place
about its own bbox; clipped -> identity); MirrorAllAcrossVMid,
MirrorAllAcrossHMid (objects reflected across the grid midline,
overlaid on bg; collisions: reflected cell wins); TransposeEachObj
(each object transposed about its bbox top-left; clipped -> identity);
RotEachObj90 (likewise, rotation).

Sorting / ranking (6): SwapPositionsBySizeLR, SwapPositionsBySizeTB
(objects' positions permuted so size order matches left-to-right /
top-to-bottom order of their original bbox anchors); KeepTop2,
KeepTop3 (largest objects kept, rest -> bg); RemoveSmallest2;
RankRecolorAsc (objects recolored by size rank onto the present
non-bg colors sorted ascending).

Counting constructs (6): CountObjsBar (output = 1 x n_objects bar of
the most frequent non-bg color); CountColorsBar; ReplicateByCount
(input tiled horizontally n_objects times; >30 wide -> identity);
LargestSizeSquare (k x k solid of the largest object's color,
k = its cell count; k > 30 -> identity); KeepObjsWithHoles,
RemoveObjsWithHoles (hole = FillHoles-style enclosed bg).

Per-object scale / shape (4): ScaleLargest2x (about bbox top-left;
clipped -> identity); StampSmallestMirrored (copy of smallest object
placed point-reflected through grid center; collision cells: copy
wins); FillObjBBoxes (each object's bbox interior filled its color);
OutlineObjects (each object reduced to its bbox border cells).

Color arithmetic (6): ColorShiftUp, ColorShiftDown (non-bg c ->
c+/-1 mod 10, skipping bg: if result == bg, step once more);
SwapMinorityMajority (least vs most frequent non-bg colors swapped);
InvertPaletteRank (present non-bg colors remapped: frequency rank i
-> rank (K-1-i)); BgSwapLeast (bg color swapped with least frequent
color); RecolorAllMajority (all non-bg -> most frequent non-bg).

Positional / structural (10): MoveLargestToCenter (bbox center to
grid center, rounded up-left; clipped -> identity); AlignObjsLeft,
AlignObjsTop (each object translated to touch that edge, other
coordinate kept); SpreadRow (objects re-placed left-to-right in
discovery order along the top row band with 1-cell gaps; doesn't
fit -> identity); CenterColumnObjs (each object's bbox center moved
to the center column, row kept); BorderFrame (1-cell frame of most
frequent non-bg color); FoldH, FoldV (right/bottom half mirrored
onto left/top half, non-bg wins; odd dimension: middle line kept;
output = the half, like PaneAnd's dims); DropBorderTouching,
KeepBorderTouching (objects touching any edge removed / kept).

## Synthetic families (discovery substrate; real ARC never used)

Generator seed 993850. A family = a hidden transform = composition
of length 1-3 sampled uniformly over U (length weights 0.5/0.3/0.2),
applied to random grids: dims uniform 6-18, bg 0, 2-4 non-bg colors,
3-7 objects of size 1-9 placed without overlap. Per family: 60 items
(40 M2-train / 10 M2-validation / 10 discovery-probe). 60 discovery
families + 20 held-out families (M2 competence measurement only).
Degenerate samples (transform == identity on an item) resampled at
generation, max 100 tries, else family redrawn.

## Media and evidence bars (frozen before discovery)

- **M1 (symbolic):** exhaustive enumeration over U (len <= 3, budget
  1e7/family) of fitting programs for each discovery family's probe
  items. Evidence for candidate u: **load-bearing frequency** = share
  of the 60 families where u appears in the canonical (first in
  enumeration order) minimal-length fitting program AND no equal-
  length fitting program avoids u. **M1 bar: >= 0.15.**
- **M2 (neural):** the […] small transformer architecture (~1M params,
  grid-pair in/out, CPU), one model per discovery family batch
  trained on the 40-item splits; competence = held-out exact-match
  on the 20 held-out families' models: **frozen competence bar:
  mean >= 0.50** (else the design note's fallback fork, researcher
  chooses (a)/(b), logged). Evidence for u: the -003/-004-proven
  correlation matcher — u's applicability signature (binary vector
  over the pooled discovery-probe items: does u alter this item's
  input) vs M2 hidden-feature signatures; statistic = max |Pearson
  r| over features; 20,000-perm null (multiplicity inside the
  null); **M2 bar: p < 0.05/40** (Bonferroni over U).
- **Spike-in gate before M2 reading:** 5 synthetic planted
  applicability features (noise sd 0.5, seed 993900), >= 4/5
  recovered at the corrected bar, else the M2 side is
  instrument-blind -> fallback fork applies.

## Triangulation and arms

- Survivor floor = candidates passing BOTH bars. **T = top 10** by
  M1 frequency, ties by M2 |r| desc, then name asc; |floor| < 10 ->
  T = floor.
- **R = |T| ops drawn uniformly from U \ {} (full U), seed 993800**,
  redrawn once if R == T as sets (record both draws).
- X = tier-3's ten (already measured; context only).

## Measurement (per arm, identical)

v4+T and v4+R as separate alphabets; the B4 §4 metric on the 1000
ARC-AGI-2 training tasks at the A1 budget (len <= 3, 1M nodes, cap
2000, R1): N (newly reachable vs v4), C (conversion), FP, regression
guard (every v4-solved task stays solved; violation = arm invalid).
**Primary decisional outcome: newly SOLVED training tasks (R1,
test-correct), T vs R.** Pre-filed readings (the third promoted to a
full reading at signature, researcher-directed, pre-implementation):
1. T > R -> provenance-positive at this surface.
2. T <= R with (T + R) >= 2 new solves -> provenance-null/negative
   (publishable either way).
3. **UNINFORMATIVE UNIVERSE: T + R <= 1 new solve -> U itself adds
   ~no reach at this budget; the provenance comparison is
   UNINFORMATIVE on this instance and is reported as a statement
   about U, explicitly NOT as a triangulation negative.** A rerun
   with a richer U is licensed as a fresh preregistration, not a
   rescue of this one.
Counts reported exactly; no significance theater at these
magnitudes.
Eval read: ONE, only for arms with >= 1 new training solve, after
the training reading is recorded.

## Addendum 2026-08-24 — fork (a) activated: M1b, the second symbolic medium

Researcher chose fork (a) (DECISIONS 2026-08-24). Claim class for all
B5 conclusions is hereby CROSS-INSTRUMENT (two independent symbolic
searchers), no longer cross-medium; every writeup sentence carries
this. M1b design frozen below BEFORE any M1b run; it is mechanism +
seeds only and references no observed evidence value (the M1 e1
ranking, already opened under v2, informs nothing here).

**M1b (frozen):** stochastic greedy beam search, deliberately
different inductive biases from M1's exhaustive shortest-first
enumeration on every declared axis:
- search: beam width 8, depth <= 3, 20 restarts/family, per-restart
  shuffled op order (seed 993950 + family index * 100 + restart);
- scoring: mean per-item CELL agreement on the 10 probe items
  (partial credit — M1 used exact-fit-only);
- acceptance: first program reaching exact fit on all 10 probe items
  (first-found, NOT shortest — a 3-op fit found early beats a 2-op
  fit never explored);
- evidence e1b(u) = share of the 60 discovery families whose
  first-found fitting program contains u; bar: rank-based top-20 by
  e1b, ties by name asc (v2 precedent).

**M1b qualification gate (spike-in analog, before discovery is
read):** 10 fresh calibration families (generator seed 993960,
disjoint from discovery and held-out); M1b qualifies if it finds a
fitting program for >= 8/10 AND the hidden program's ops appear in
the found program for >= 80% of fitted calibration families.
Unqualified -> instrument-blind, recorded; fork (b) becomes the
default pending researcher.

**Floor and arms (unchanged logic, M2 slot replaced):** survivor
floor = top-20(e1, M1) INTERSECT top-20(e1b, M1b); T = top 10 of
floor by rank-product (M1 rank x M1b rank), ties by name asc;
|floor| < 10 -> T = floor. R, measurement, readings 1-3, eval-read
rule: all exactly as v2 froze them.
